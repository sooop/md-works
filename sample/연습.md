\# 우클릭 "클립보드로 복사" (SendTo) 구현\
\
\## 목적\
탐색기에서 텍스트 파일(txt, csv, json, md, html 등)을 우클릭해 내용을 UTF-8 그대로 클립보드에 복사한다.\
수동으로는 `bat -pp {파일} | ucopy -n` 으로 하던 일이다.\
\
\## 방식\
Windows **SendTo** 폴더에 바로가기 하나를 둔다. 레지스트리는 수정하지 않는다.\
\
\- 메뉴 위치: 파일 우클릭 → 보내기 → 클립보드로 복사\
- 바로가기: `%APPDATA%\Microsoft\Windows\SendTo\클립보드로 복사.lnk`\
- 대상: `C:\Users\sooop\scoop\shims\nu.exe`\
- 인수: `C:\apps\bin\copy-to-clipboard.nu`\
\- 창 스타일: 최소화 (콘솔 깜빡임 최소화)\
- 래퍼 스크립트: `C:\apps\bin\copy-to-clipboard.nu`\
\
\## 래퍼 동작\
1\. SendTo가 넘긴 파일 경로를 인수로 받는다.\
2. 파일마다 `bat -pp --color=never` 로 내용을 읽는다.\
3. 파일이 둘 이상이면 각 내용 앞에 `--- 파일명 ---` 을 붙이고 빈 줄로 이어 붙인다. 하나면 내용만 쓴다.\
4. 결과를 `C:\apps\bin\ucopy.exe -n` 에 넘겨 클립보드에 복사한다.\
\
\## 설계 결정\
\| 항목 | 선택 | 이유 |\
\|---|---|---|\
\| 메뉴 방식 | SendTo | 레지스트리를 건드리지 않고 되돌리기 쉽다 |\
| 래퍼 언어 | nu | `.cmd` 는 코드페이지 때문에 한글 경로가 깨진다 |\
| 클립보드 도구 | `ucopy.exe` | 시스템 `clip` 은 한글이 깨진다 |\
\| 여러 파일 | 구분선 + 이어 붙임 | 한 번에 복사하면서 출처를 구분한다 |\
\
\## 검증\
한글과 악센트 문자가 든 파일로 래퍼를 직접 실행해, `ucopy -p` 로 읽은 값이 원문과 같음을 확인했다.\
SendTo 메뉴에서 우클릭으로 실행하는 경로는 아직 확인하지 않았다.\
\
\## 한계와 후속\
- SendTo는 확장자 필터가 없다. 바이너리를 보내면 `bat` 출력이 그대로 복사된다.\
\- 콘솔 창이 최소화 상태로 잠깐 뜬다.\
\- 확장자를 한정하거나 우클릭 최상위에 두려면 HKCU 레지스트리 컨텍스트 메뉴를 추가한다.\
Windows 11에서는 "더 많은 옵션 표시" 안에 나타난다.\
\
\## 제거\
- `SendTo\클립보드로 복사.lnk` 삭제\
- `C:\apps\bin\copy-to-clipboard.nu` 삭제
