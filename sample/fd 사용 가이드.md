# 무엇을 하는 앱일까

씬 더 쓰기 쉽고 빠르ㅇ고 편리한 도구입니다.

shell

Copy

1

fd \[옵션] \[패턴] \[경로]

옵션이나 사용법 등을 좀 더 자세하기 다루기 전에 기본적인 동작 방식을 알아두면 이해에 도움이 됩니다.

* 기본적으로 숨김 파일이나, `.gitignore`에 언급된 패턴은 찾지 않습니다.
* 대소문자 구분은 smart case가 기본적으로 적용됩니다.
* 명령 실행은 병렬처리가 적용됩니다.

## 멘탈 모델

fd는 결국 디렉터리 아래의 노드 트리에서 조건에 맞는 파일이나 디렉터리를 필터링하는 필터 파이프라인입니다. fd는 디렉터리를 재귀적으로 방문하면서 각각의 항목을 아래 순서의 필터에 통과 시키고 남은 것을 출력합니다.

1. 무시 규칙: 숨김파일이나 .gitignore, .ignore, .fdignore 등에 해당되면 탈락.

1) 구조 조건: 깊이(-d)나 수정시간, 소유자 등의 옵션 조건에 맞지 않으면 탈락
2) 이름 패턴: 정규식이나 글로브 패턴에 맞지 않으면 탈락
3) 그리고 출력 할 때에는 출력 방식을 지정할 수 있습니다: 상세출력(-l), -x/-X는 인자로 전달하여 명령 실행

혼동하면 안되는 중요한 규칙중에 하나는 fd는 패턴이 기본적으로 파일 이름에만 적용된다는 것입니다. `fd src`는 파일 이름에 src가 들어간 항목을 찾지, 경로에, 즉 src/ 아래 디렉토리를 찾지 않습니다.

또한 패턴은 정규식입니다. `fd 'test.*[.]py$` 와 같이 정규식 패턴을 작성합니다. 만약 글로브 확장을 원한다면 -g 옵션을, 정규식 메타문자 없이 문자 그대로 찾기를 원한다면 -F 옵션을 씁니다.

패턴은 부분일치로 찾습니다. 전체 일치가 필요하다면 옵션 대신 ^test\$와 같이 정규식 앵커를 사용합니다.

<br />

### 인자 순서 : 패턴이 ㅓ먼저

find와 정반대의 순서라 익숙해지지 못하면 자주 틀립니다. 패턴 없이 경로만 지정하면 `fd .` 으로 모든 이름에 매칭하는 패턴을 지정합니다.
