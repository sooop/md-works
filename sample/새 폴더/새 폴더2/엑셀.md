# 엑셀 입문자·중급자 완벽 가이드

## 1부: 초심자용 필수함수들

### 함수가 필요한 이유

스프레드시트에서 함수가 등장한 이유는 단순합니다. 데이터가 수십 개일 때는 손으로 계산할 수 있지만, 수백 개, 수천 개가 되면 불가능해집니다. 함수는 이러한 반복 작업을 자동화하고, 데이터가 변할 때마다 자동으로 재계산되는 "살아있는 수식"을 만들어줍니다.

초심자가 습득해야 할 함수들은 다음과 같은 기준으로 선별됩니다:
- **계산의 자동화** (SUM, AVERAGE, COUNT)
- **데이터의 선별** (IF, COUNTIF)
- **텍스트 조작** (CONCATENATE, LEN, FIND)
- **기본적 조건 분기** (IF, AND, OR)

이들은 엑셀의 가장 기초적인 작업들이면서도, 이들을 이해하면 더 복잡한 함수들도 자연스럽게 습득할 수 있는 토대가 됩니다.

### SUM, AVERAGE, COUNT: 집계의 기초

데이터 분석의 출발점은 "전체 합이 얼마인가", "평균은 어떻게 되나", "몇 개인가"라는 질문입니다.

**SUM(범위)** 은 범위 내의 모든 수를 더합니다. 만약 A1:A10에 월별 매출 데이터가 있다면, `=SUM(A1:A10)`으로 연간 총매출을 한 번에 구할 수 있습니다. 이후 한 셀의 값만 변경되어도 합계는 자동으로 업데이트됩니다.

**AVERAGE(범위)** 는 수의 합을 개수로 나눈 평균값입니다. 전체 성적의 평균을 구할 때처럼 특정 시점의 "대표값"을 알아야 할 때 사용됩니다.

**COUNT(범위)** 는 숫자가 들어있는 셀의 개수만 센다는 점이 중요합니다. 빈 셀이나 텍스트는 세지 않습니다. 텍스트도 포함해서 세려면 COUNTA를 사용합니다.

### IF: 조건부 판단의 시작

`=IF(조건, 참일때값, 거짓일때값)`은 엑셀에서 가장 중요한 함수 중 하나입니다. 데이터가 특정 조건을 만족하느냐에 따라 다른 값을 표시하는 것이 핵심입니다.

예를 들어 매출이 1000만 원 이상이면 "목표달성", 미만이면 "미달성"으로 표시하려면:
```
=IF(A1>=10000000, "목표달성", "미달성")
```

IF의 강력함은 중첩(Nested IF)에서 발휘됩니다. 학점을 90점 이상 A, 80점 이상 B, 70점 이상 C로 부여하려면:
```
=IF(A1>=90, "A", IF(A1>=80, "B", IF(A1>=70, "C", "F")))
```

하지만 이렇게 중첩이 3단계를 넘어가면 읽기 어려워지는데, 이 문제는 나중에 배울 함수들로 우아하게 해결됩니다.

### COUNTIF, SUMIF: 조건을 가진 집계

SUM과 AVERAGE는 범위 전체를 집계하지만, 특정 조건을 만족하는 데이터만 집계해야 할 때가 있습니다.

**COUNTIF(범위, 조건)** 는 조건을 만족하는 셀의 개수를 센다는 IF의 개념을 집계에 적용한 것입니다. 예를 들어 영업팀 직원 목록에서 "부산" 지역의 직원이 몇 명인지 알아야 한다면:
```
=COUNTIF(B:B, "부산")
```

**SUMIF(범위, 조건, 합계범위)** 는 조건에 맞는 행의 값만 더합니다. 지역별로 분류된 매출 데이터에서 부산 지역의 총매출만 구하려면:
```
=SUMIF(B:B, "부산", C:C)  
// B열에서 "부산"인 행의 C열 값만 더한다
```

이 함수들의 핵심은 "조건과 데이터가 다른 열에 있다"는 구조입니다. 조건이 변해도 수식은 동일하게 작동합니다.

### CONCATENATE, LEN, FIND: 텍스트 처리

엑셀이 숫자만 다루는 도구가 아니라면, 텍스트 조작도 중요합니다.

**CONCATENATE(값1, 값2, ...)** 또는 더 간단히 **&** 연산자로 텍스트를 결합합니다:
```
=A1&" "&B1  // "홍길동"과 "부산"을 "홍길동 부산"으로 결합
```

**LEN(텍스트)** 는 텍스트의 길이(문자수)를 반환합니다. 데이터 검증에 사용됩니다. 예를 들어 전화번호 형식이 올바른지 확인하려면:
```
=IF(LEN(A1)=11, "유효", "오류")
```

**FIND(찾을텍스트, 범위)** 는 텍스트의 위치를 반환합니다. "2024년"이라는 텍스트에서 "년"의 위치를 찾아서 "2024" 부분만 추출하는 등의 데이터 정제에 사용됩니다.

### 함수 조합의 시작

초심자 함수들이 강력해지는 순간은 이들을 조합할 때입니다:
```
=AVERAGEIF(B:B, "부산", C:C)  
// 부산 지역의 평균 매출을 구한다
```

이처럼 IF의 개념을 다른 함수에 통합하면, 단순 집계에서 조건부 집계로 한 단계 나아갑니다.

## 2부: XLOOKUP 및 집계를 위한 중·고급함수

### VLOOKUP에서 XLOOKUP으로: 데이터 연결의 진화

엑셀 초급자들이 가장 어려워하는 개념 중 하나가 **여러 표를 하나로 연결하는 것**입니다. 예를 들어, 고객ID 목록이 있을 때 각 고객의 이름과 주소를 다른 표에서 찾아와야 하는 상황입니다.

전통적인 VLOOKUP은 이를 해결하지만 한계가 있습니다:
- 반드시 찾는 열이 왼쪽에 있어야 한다
- 반환 열이 찾는 열보다 오른쪽에 있어야 한다
- 복잡한 구문으로 인해 실수가 잦다

```
=VLOOKUP(A1, 다른표!A:C, 3, FALSE)
// A1의 값을 다른표의 A열에서 찾아서 같은 행의 3번째 열 값을 반환
```

**XLOOKUP은 이러한 제약을 모두 제거합니다**:
```
=XLOOKUP(찾을값, 찾을범위, 반환범위, [없을때값])
```

핵심 차이점은 **찾을 범위와 반환 범위를 명시적으로 분리**한다는 것입니다. 열의 순서에 관계없이 작동하고, 없을 때의 값도 직관적으로 지정할 수 있습니다:
```
=XLOOKUP(A1, 다른표!B:B, 다른표!D:D, "정보없음")
// B열에서 A1을 찾아 D열 값을 반환, 못 찾으면 "정보없음" 표시
```

XLOOKUP은 또 다른 강력한 기능으로 **-1 옵션**을 지원합니다. 이는 "정확히 일치하는 값이 없을 때 바로 아래 값을 반환"하라는 의미로, 점수 범위(0~59점은 F, 60~79점은 C 등)에 따른 분류에 매우 유용합니다.

### INDEX & MATCH: XLOOKUP 이전의 우아한 해법

XLOOKUP이 없는 버전의 엑셀을 사용한다면, INDEX와 MATCH를 조합하는 방법이 있습니다. 이는 원리적으로도 XLOOKUP보다 유연합니다.

**MATCH(찾을값, 범위, [매칭타입])** 는 찾을 값의 위치(행 번호)를 반환합니다. XLOOKUP의 "찾을범위" 부분을 담당합니다:
```
=MATCH(A1, B:B, 0)  // A1을 B열에서 찾아서 몇 번째 행인지 반환
```

**INDEX(범위, 행번호, [열번호])** 는 그 위치에 있는 값을 반환합니다:
```
=INDEX(C:C, 5)  // C열의 5번째 행 값을 반환
```

이 둘을 결합하면:
```
=INDEX(반환범위, MATCH(찾을값, 찾을범위, 0))
```

XLOOKUP이 선택지가 아닐 때, 이 조합은 모든 상황에서 작동합니다. 양쪽 방향 찾기도 가능하고, 범위의 순서에 무관합니다.

### SUMPRODUCT: 복잡한 조건을 가진 집계

여러 조건을 동시에 만족하는 데이터를 집계해야 할 때가 있습니다. 예를 들어 "부산 지역 AND 2024년 AND 상품A"인 매출의 합계를 구하려면?

SUMIFS를 사용할 수도 있지만:
```
=SUMIFS(금액범위, 지역범위, "부산", 연도범위, 2024, 상품범위, "상품A")
```

조건이 많아질수록 길어집니다. 더 유연한 접근은 **SUMPRODUCT**입니다:
```
=SUMPRODUCT((지역범위="부산")*(연도범위=2024)*(상품범위="상품A")*금액범위)
```

이 구문의 원리는 다음과 같습니다:
- 각 조건은 TRUE/FALSE 배열을 생성합니다
- 이들을 곱하면 모든 조건을 동시에 만족하는 행만 1이 됩니다
- 그 결과를 금액과 곱해서 합산합니다

SUMPRODUCT의 장점은 **조건 자체도 수식이 될 수 있다**는 점입니다. 단순 "="만 아니라 ">", "<" 등의 비교 연산자도 사용 가능합니다.

### FILTER: 데이터 필터링의 새로운 방식

여러 조건에 맞는 데이터 행 전체를 가져와야 할 때가 있습니다. 과거에는 자동필터를 수동으로 적용했지만, **FILTER 함수는 이를 수식으로 자동화합니다**:
```
=FILTER(반환범위, (조건범위="부산")*(수량범위>100))
```

FILTER는 조건을 만족하는 모든 행을 반환합니다. 여기서 핵심은 **결과가 동적이라**는 것입니다. 원본 데이터가 변하면 필터 결과도 자동으로 갱신됩니다.

## 3부: 피벗테이블

### 왜 피벗테이블이 필요한가

엑셀을 다루다 보면 다음과 같은 상황을 마주칩니다: 
- 수백 개 행의 거래 데이터가 있는데, "지역별 월별 총매출"을 한눈에 보고 싶다
- 고객 리스트에서 "상품 카테고리별로 누가 가장 많이 구매했는가"를 알아야 한다

이런 "데이터의 형태를 완전히 바꿔서 봐야 하는" 상황이 바로 피벗테이블이 필요한 순간입니다. SUMIF나 VLOOKUP으로도 수작업으로 만들 수 있지만, 피벗테이블은 **마우스 클릭만으로 자동화**합니다.

### 피벗테이블의 구조

피벗테이블은 다음 네 가지 영역으로 구성됩니다:

**행 영역(Row Area)**: 왼쪽 세로 방향으로 나열할 항목. 지역, 상품명, 고객명 등.

**열 영역(Column Area)**: 위에서 오른쪽으로 나열할 항목. 월, 분기, 연도 등. 

**값 영역(Values Area)**: 실제 계산할 데이터. 합계, 평균, 개수 등.

**필터 영역(Filters)**: 전체 피벗테이블에서 특정 조건만 보고 싶을 때 사용.

예를 들어, 원본 데이터가 날짜, 지역, 상품, 판매량 순서로 되어있다면:
- 행: 지역
- 열: 월(날짜에서 추출)
- 값: 판매량(합계)

이렇게 설정하면 지역 × 월 형태의 표가 자동으로 만들어집니다. 데이터가 추가되어도 피벗테이블을 "새로고침"하면 자동 반영됩니다.

### 피벗테이블 만드는 법

1. 원본 데이터 범위를 선택 (행 번호와 열 이름 포함)
2. 삽입 > 피벗테이블 > 새 워크시트 선택
3. 오른쪽 패널에서 필드를 네 영역으로 끌어다 놓기
4. 완성

핵심은 **원본 데이터의 형태가 중요하다**는 것입니다. 각 열이 명확한 의미를 가져야 하고(행번호, 날짜, 지역, 상품, 판매량), 데이터가 이미 정리되어 있어야 합니다.

### 계산된 필드와 슬라이서

피벗테이블을 만든 후 추가 조작이 필요할 수 있습니다.

**계산된 필드**는 피벗테이블 내에서 새로운 계산값을 만듭니다. 예를 들어 판매량과 판매가격이 있을 때, 그 곱인 "총매출"을 계산된 필드로 추가할 수 있습니다.

**슬라이서**는 피벗테이블을 대화형으로 필터링하는 도구입니다. 오른쪽에 "지역" 슬라이서를 두고 "부산"만 선택하면, 피벗테이블이 실시간으로 부산 데이터만 보여줍니다. 대시보드를 만들 때 매우 유용합니다.

## 4부: 통계 검정함수

### 통계 검정이 필요한 이유

데이터를 다루다 보면 "이 차이가 우연일까, 아니면 의미 있는 차이일까"라는 질문을 하게 됩니다.
- A 광고 캠페인의 클릭률이 B보다 높은데, 이게 진짜 A가 더 효과적이라는 뜻일까?
- 신제품 사용자 만족도가 기존 제품보다 높은데, 충분히 신뢰할 만한가?

이때 사용하는 것이 통계 검정입니다. 검정을 통해 우리의 관찰(표본)이 "실제 차이"를 반영하는지, 아니면 "운의 변동"일 가능성이 높은지를 판단합니다.

### p값(유의확률)의 개념

모든 통계 검정의 결과는 **p값**으로 표현됩니다. p값의 의미는 다음과 같습니다:

"만약 두 집단이 실제로는 같다면, 지금 우리가 관찰한 정도의 차이(또는 그 이상)가 나타날 확률"

예를 들어 p값이 0.05라면, "만약 A와 B 캠페인의 실제 효과가 같다면, 현재 정도의 차이가 나타날 확률이 5%"라는 뜻입니다. 이 확률이 충분히 낮으면(보통 5% 이하), 우리는 "두 캠페인은 실제로 다르다"고 결론 지을 수 있습니다.

### T.TEST: t-검정 함수

**t-검정**은 두 그룹의 평균이 실제로 다른지를 판단합니다. 이는 다음과 같은 상황에서 사용됩니다:
- A 지점의 월평균 매출과 B 지점의 월평균 매출이 다른가?
- 치료 전 환자들의 혈압과 치료 후 혈압이 달라졌는가?

```
=T.TEST(배열1, 배열2, 테일, 타입)
```

각 파라미터의 의미:
- **배열1, 배열2**: 비교할 두 데이터 그룹
- **테일**: 1(단측검정: 더 크거나 작은지) 또는 2(양측검정: 다른지)
- **타입**: 1(쌍체검정: 같은 개체의 전후), 2(독립표본: 다른 개체), 3(등분산 가정 안함)

예를 들어, 지점 A의 10개월 매출(A1:A10)과 지점 B의 10개월 매출(B1:B10)을 비교한다면:
```
=T.TEST(A1:A10, B1:B10, 2, 2)
// 양측검정, 두 그룹이 다른 개체(독립표본)
```

결과 p값이 0.05 이하면 "두 지점의 평균 매출이 통계적으로 유의미하게 다르다"고 해석합니다.

### CHISQ.TEST: 카이제곱 검정

**카이제곱 검정**은 범주형 데이터에 사용됩니다. t-검정이 "평균의 차이"를 본다면, 카이제곱 검정은 "분포의 형태"를 봅니다.

예를 들어:
- 온라인 쇼핑몰에서 남성이 구매한 상품 카테고리 분포와 여성이 구매한 분포가 실제로 다른가?
- 특정 지역에서 제품 불량률이 전사 평균과 다른가?

```
=CHISQ.TEST(관찰도수, 예상도수)
```

관찰도수는 실제 데이터이고, 예상도수는 "만약 차이가 없다면 기대되는" 분포입니다.

### Z.TEST: z-검정

**z-검정**은 표본이 크고 모집단의 표준편차를 알 때 사용합니다. t-검정보다 엄격하다고 보면 됩니다.

```
=Z.TEST(배열, 가설값, [표준편차])
```

예를 들어 고객 만족도의 평균이 본래 70점이었는데, 새로운 정책 후 50명의 샘플에서 평균이 75점이 되었다면:
```
=Z.TEST(샘플범위, 70, 모집단표준편차)
```

### 검정 결과 해석하기

모든 검정에서 나오는 p값 해석은 동일합니다:

- **p < 0.05**: 통계적으로 유의미한 차이 (귀무가설 기각)
- **p ≥ 0.05**: 통계적 차이를 주장할 증거 부족 (귀무가설 채택)

주의할 점은 **p값이 작다 ≠ 실제로 중요한 차이**라는 것입니다. 표본이 크면 작은 차이도 통계적으로 유의미하게 나타날 수 있습니다. 따라서 p값과 함께 **효과크기(두 평균의 차이, 또는 상관계수 등)**도 함께 봐야 합니다.

```
=AVERAGE(배열1)-AVERAGE(배열2)  // 평균의 차이를 직접 계산해서 확인
```

이렇게 p값이 0.03이면서 평균 차이가 1000원이라면, "통계적으로 유의미하지만 실무적으로는 무시할 수 있는 차이"일 수 있습니다.
